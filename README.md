> Lightweight Drag-and-Drop Task & Project Management Board built with pure Vanilla JavaScript and HTML5 Drag and Drop API.

---

## 🌟 Features

- **🎯 Drag & Drop Interface**: Seamlessly drag tasks across To Do, In Progress, and Done columns.
- **🏷️ Priority Tagging & Filtering**: Categorize by High, Medium, or Low priority with interactive filter controls.
- **⚡ Zero Dependencies**: Pure HTML5, CSS3, and JavaScript implementation.
- **🧪 Unit Tested**: 100% test coverage using Node.js native test runner.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/kanban-flow.git
cd kanban-flow
npm start
```

Run unit tests:
```bash
npm test
```
